# Farm Forward Foundation

PHASE 1 — FOUNDATION, DESIGN SYSTEM & HERO

Build the foundation of a premium AgriTech startup landing page.

Product

We are building an AI-powered farm-to-market marketplace connecting:

Farmers + FPOs ↔ Verified Buyers ↔ Consumers

The platform will eventually provide:

Direct agricultural marketplace

AI demand forecasting

Market/price intelligence

Buyer-supplier matching

Order aggregation

Smart logistics

Route optimization

The core message is:

"Sell Smarter. Buy Direct. Move Fresh Produce Faster."

IMPORTANT SCOPE

For this phase ONLY build:

Design system

Global styles

Responsive navbar

Hero section

Basic CTA placeholders

Responsive foundation

Do NOT build the other landing-page sections yet.

Do NOT build real backend, authentication, payments, real AI APIs, logistics APIs or database functionality.

DESIGN DIRECTION

The website should feel:

Fresh

Natural

Intelligent

Trustworthy

Modern

Premium

Optimistic

Technology-driven

Visual identity:

Agriculture + Growth + Technology + Trust

Use a sophisticated green palette.

Prefer:

Light green backgrounds

Soft pastel green

Fresh medium green CTA buttons

Deep green typography

White/cream surfaces

Subtle earthy accents

Avoid:

Neon green

Excessive gradients

Generic blue corporate design

Excessive glassmorphism

Excessive shadows

Childish rounded cards

Clutter

Use excellent contrast and accessible typography.

AGRICULTURAL MOTION

Introduce subtle growth-inspired animation:

Small leaves

Growing crops

Gentle floating agricultural elements

Subtle farm-to-market movement

Animations must be lightweight and elegant.

Respect prefers-reduced-motion.

Do not make animations distracting.

NAVBAR

Create a sticky responsive navbar.

Left:

[Brand Logo / Brand Name]

Navigation:

Marketplace

For Farmers

For Buyers

How It Works

AI Insights

Logistics

About

Right:

Login
Join Marketplace

Mobile:

Hamburger menu

Smooth mobile menu

Touch-friendly links

CTA remains accessible

Navbar should slightly compact when scrolling.

HERO

Create a premium, visually impressive hero section.

Headline:

Sell Smarter. Buy Direct. Move Fresh Produce Faster.

Supporting copy:

Connect directly with farmers, FPOs and verified buyers while using AI-powered demand insights and smarter logistics to make agricultural trade more transparent and efficient.

Primary CTA:

Check My Crop

Secondary CTA:

Post Your Requirement

Supporting microcopy:

Fair Prices • Direct Sourcing • AI Insights • Smart Logistics

The hero visual should communicate:

Farmer → Produce → Digital Marketplace → AI → Logistics → Buyer

Use an elegant agricultural illustration/visual composition rather than a generic stock-photo-heavy design.

Include subtle crop-growth animations.

RESPONSIVENESS

Design mobile-first.

The hero must work beautifully on:

Small mobile

Large mobile

Tablet

Laptop

Desktop

Large desktop

Requirements:

No horizontal scrolling

Responsive typography

Responsive images

Touch-friendly buttons

Proper spacing

No overlapping content

No clipped text

COMPONENT ARCHITECTURE

Use:

React

TypeScript

Tailwind CSS

shadcn/ui where appropriate

Create reusable components:

Navbar
Hero
CTAButton
Container
SectionWrapper

Keep the architecture clean and reusable because more sections will be added in later phases.

QUALITY BAR

Do not make this look like a generic AI-generated landing page.

It should feel like a credible funded AgriTech startup.

Focus heavily on:

Visual hierarchy
Typography
Spacing
Responsive behavior
Premium UI
Subtle motion
Clear CTA hierarchy

Before finishing this phase, verify the hero at mobile, tablet and desktop widths.
